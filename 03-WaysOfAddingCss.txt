//!Ways of Adding CSS
-->There are three ways to add CSS to an HTML document.
1)Inline CSS
2)Internal CSS
3)External CSS

--------------------------------------------------------------
//!1. Inline CSS
-->Inline CSS is written directly inside the opening HTML tag using the style attribute.
//!Example:
<h1 style="color: white; background-color: blue;">
    Let's dive into CSS
</h1>
--------------------------------------------------------------
//!2. Internal CSS
-->Internal CSS is written inside the <style> tag within the HTML document.
-->It is recommended to place the <style> tag inside the <head> section.
//!Example:
<!DOCTYPE html>
<html>
<head>
    <style>
        h1{
            color:white;
            background-color:blue;
        }
    </style>
</head>
<body>
    <h1>Let's dive into CSS</h1>
</body>
</html>
--------------------------------------------------------------
//!3. External CSS
-->External CSS means writing all CSS code in a separate file with the .css extension.
-->The CSS file is connected to the HTML document using the <link> tag.
//!Example:
<!DOCTYPE html>
<html>
<head>
  <link rel="stylesheet" href="./style.css">
</head>
<body>
   <h1>Let's dive into CSS</h1>
</body>
</html>
--------------------------------------------------------------
//!CSS Priority Order
-->When multiple CSS rules target the same element, the browser decides which rule should be applied.
1)Inline Css
2)Internal or External Css (based upon latest value inside head tag)

//!Note:
-->To override the priorities we use !important
h1{
    color:red !important;
}
